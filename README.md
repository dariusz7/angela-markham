# Angela Markham – sitio web

Sitio estático (HTML + CSS + JS, sin build) para Angela Markham, terapeuta individual, de pareja y familiar en Clifton, Bristol. Publicado con GitHub Pages desde la rama `main`.

- `index.html` – todo el contenido (una sola página con secciones)
- `styles.css` – estilos
- `script.js` – menú móvil y formulario de contacto
- `assets/` – foto, imagen para redes sociales y favicon

## Formulario de contacto

Todavía **no está conectado** a ningún servicio: al enviarlo valida los campos y le ofrece al visitante abrir el mensaje en su programa de correo (mailto a therapy@angelamarkham.co.uk). Para activarlo, conectar un servicio (Formspree, Web3Forms, etc.) en el bloque marcado `NOT CONNECTED` de `script.js`.
